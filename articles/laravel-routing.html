شرح Laravel Routing خطوة بخطوة

الـ Routing في Laravel هو المسؤول عن ربط الرابط (URL) بالوظيفة المناسبة داخل التطبيق.

أين يوجد ملف Routes ؟

ستجده داخل: 

routes/web.php

مثال بسيط

Route::get('/home', function () {
    return view('home');
});

عند زيارة /home سيتم عرض صفحة home.

تمرير متغير داخل الرابط

Route::get('/user/{id}', function ($id) {
    return "User ID: " . $id;
});

الآن يمكنك استقبال متغير من الرابط.
