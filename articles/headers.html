حل مشكلة headers already sent في PHP

يظهر هذا الخطأ غالباً عند استخدام session_start() أو إعادة التوجيه باستخدام header(). ويعني أن PHP أرسلت مخرجات إلى المتصفح قبل إرسال ترويسات HTTP.

سبب المشكلة

وجود أي مسافة أو سطر فارغ قبل بداية كود PHP أو بعد نهايته.

الحل
  • لا تضع مسافات قبل بداية الملف
  • لا تستخدم echo قبل header
  • لا تضع ?> في نهاية الملف

حل إضافي


ob_start();
