حل مشكلة headers already sent في PHP

يعد هذا الخطأ من أكثر الأخطاء شيوعاً لدى مطوري PHP خاصة عند استخدام sessions أو التحويل باستخدام header(). رسالة الخطأ غالباً تظهر بهذا الشكل: 


Warning: Cannot modify header information - headers already sent

ما معنى الخطأ؟

بروتوكول HTTP يتطلب إرسال معلومات الهيدر أولاً قبل أي محتوى HTML. عند قيام PHP بإرسال أي نص للمتصفح (حتى مسافة أو سطر فارغ) يعتبر أن الإخراج بدأ بالفعل، وبعدها لا يمكن تعديل الهيدر أو تنفيذ عملية redirect.

أسباب حدوث المشكلة

  • وجود مسافة قبل بداية كود PHP
  • استخدام echo قبل header()
  • وجود HTML قبل session_start()
  • إغلاق ملف PHP بعلامة ?> ثم إضافة سطر جديد بعده

مثال على الخطأ

الكود التالي سيؤدي إلى ظهور المشكلة:


echo "Welcome";  // بدأ الإخراج للمتصفح

header("Location: home.php");  // هنا سيظهر الخطأ

الحل الصحيح

يجب تنفيذ التحويل قبل أي إخراج:

الحل باستخدام Output Buffering

تقوم الدالة ob_start() بتأجيل إرسال الإخراج مؤقتاً، لكن يفضل دائماً إصلاح سبب المشكلة الأساسي بدلاً من الاعتماد عليها فقط.

نصيحة مهمة للمطورين

لا تقم بإغلاق ملفات PHP البحتة باستخدام ?> في نهاية الملف، لأن أي سطر جديد بعده سيعتبر إخراجاً ويؤدي مباشرة لظهور الخطأ.
