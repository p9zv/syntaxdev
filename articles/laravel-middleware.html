شرح Laravel Middleware

الـ Middleware في Laravel يعمل كطبقة فلترة قبل وصول الطلب إلى الكنترولر.

مثال عملي

php artisan make:middleware CheckUser

بعد إنشائه يمكنك استخدامه داخل routes: 

Route::get('/dashboard', function () {
    return view('dashboard');
})->middleware('checkuser');
